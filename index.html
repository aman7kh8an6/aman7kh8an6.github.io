Things I built to understand how they work.

  • ★ 1miniDBin progressA B+Tree-indexed key-value storage engine built one layer at a time. Each layer fixes a problem the one below it causes: append-only log, then an in-memory hash index, fixed 4 KB pages, an LRU buffer pool with pin counts and dirty tracking, and finally the B+Tree.
  • ★ 1drinkmix-data-warehouseA star-schema data warehouse and ETL pipeline for a beverage retail chain (BTU course project).
