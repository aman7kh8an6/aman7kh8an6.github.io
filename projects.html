Each one started as a question about how something works underneath.

  • ★ 1miniDBin progressA B+Tree-indexed key-value storage engine built one layer at a time. Each layer fixes a problem the one below it causes: append-only log, then an in-memory hash index, fixed 4 KB pages, an LRU buffer pool with pin counts and dirty tracking, and finally the B+Tree. The append-only log layer is built and runs its own test suite (6 of 7 passing). The failing test is documented on purpose: separator-framed records desynchronise when a value contains a marker byte. The fix is length-prefixed records, the way SQLite, LevelDB and Bitcask frame them.C++17, no dependencies
  • ★ 1drinkmix-data-warehouseA star-schema data warehouse and ETL pipeline for a beverage retail chain (BTU course project). Five fact and dimension tables. Deduplicated about 47,000 records across three source systems with no shared key, with idempotent loads and count reconciliation.Oracle PL/SQL, SQL
